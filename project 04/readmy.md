# My Personal Portfolio

## About Me
Hello! I am a beginner web developer learning HTML, CSS, and JavaScript. This is my personal portfolio website.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git

## Website Sections
- **About Me:** Introduction and profile photo.
- **Skills:** My programming skills.
- **Projects:** My Projects 00, 01, 02, and 03.
- **Hobbies:** My personal interests.
- **Contact:** A contact form.

## Features
- Navigation bar
- Profile photo
- Skills and project cards
- Dark theme switcher
- Contact form
- Responsive design for mobile devices

## Project Structure
```text
project 04/
├── assets/
│   └── profile.jpg
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html` in a web browser.
3. Click the **Change Theme** button to switch between light and dark themes.
